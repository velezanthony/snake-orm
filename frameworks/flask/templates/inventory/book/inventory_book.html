Movement book

The movements of a warehouse have two authors, and this page is both of them at once. The shop writes a line when an order takes units and when a customer sends them back; the floor writes one when a delivery is put away and when a count corrects the shelf. Each origin is bounded at {{ book_size }} lines on its own, which is a limit belonging to a sort and therefore something no single filter can express.

Why UNION ALL and not UNION

Two units of one SKU leaving one warehouse at one instant are two shipments. Deduplicating would print one line and leave the book short of a unit the stock still says left. The fold is possible at all because a line comes off StockLedger, a read-only view with no primary key: over the movements table the key rides on every projection and two events can never be the same row twice. {% if one_statement %} This engine takes parentheses around a bounded branch, so the whole book arrived in one statement. {% else %} This engine refuses parentheses around the branches of a compound, so each origin was read separately and merged here — by concatenating, never by folding. {% endif %}
