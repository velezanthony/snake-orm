The one question a stock listing does not answer: what do I need to reorder? These rows are not a filter written here — they come off LowStock, a read-only view that the ORM queries like a model and refuses to write to. The threshold is part of the object in the database, so this page and /api/inventory/low-stock cannot disagree about what is short.
