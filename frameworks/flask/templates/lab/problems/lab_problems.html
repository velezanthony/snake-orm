Lab · Deliberate problems

This page makes TWO classic mistakes so the panel can catch them. Open it and look at the duplicates metric.

{% include "lab/_debug_hint.html" %}

1 · A LITERAL duplicate

The same query, run twice

×2
The header and the sidebar each ask for the same published posts. Same SQL, same parameters: this is not an N+1, it is repeated work. The panel shows that query with ×2. The fix is to share the result, not to ask twice.

2 · An N+1

The same SQL, in a loop

×N
For every user its tokens are fetched in a separate query — same SQL, different parameter. The panel shows it with ×N, one per user. The fix is an include or a prefetch instead of the loop.

Open the debug panel (the floating button). You will see many queries and, at the top, how many are duplicates. Each repeated SQL also carries its possible-N+1 warning. That is the tool earning its keep: it tells "I did it twice by accident" apart from "I did it in a loop".
