Generar modelos

Espeja una BD existente a modelos Python:

snakeorm scaffold create --out models.py

Re-sincronizar (sobrescribe entero): scaffold update

Sin --out no genera: no hay ruta por defecto y falla diciéndolo.

Modelo espejo

@snake_db_first · marca un modelo como espejo: las migraciones lo IGNORAN. El esquema es del sysadmin, no nuestro.

NO hay adopción in situ: cambiarlo a @snake_model no le entrega los mandos a las migraciones, porque el histórico no conoce la tabla y el autogen solo emitiría un CreateTable, que contra la tabla existente muere. Sirve para LLEVARSE el esquema a otra base gobernada desde cero.

Nombres de las clases

La clase se llama como la tabla, en CapWords y con el esquema delante:

public.project_requests → PublicProjectRequests

--keep-underscores · deja los guiones bajos Public_project_requests

--no-schema-prefix · quita el esquema; dos esquemas con la misma tabla COLISIONAN y se avisa

No se quita el plural: eso es adivinar en inglés y rompe status, analysis o direcciones. Lo que no se puede nombrar se avisa y se deja fuera, nunca se inventa.
